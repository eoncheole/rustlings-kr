# 스마트 포인터(Smart Pointers)

Rust에서 스마트 포인터(Smart Pointer)는 메모리 주소를 담고 있으면서 다른 데이터를 참조하는 변수인데, 추가적인 메타데이터와 기능도 갖고 있어.
Rust의 스마트 포인터는 보통 가리키는 데이터를 소유하는 반면, 참조(reference)는 데이터를 빌리기만 해.
