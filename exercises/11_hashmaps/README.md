# 해시맵(Hashmaps)

*해시맵(hash map)*은 특정 키에 값을 연결할 수 있게 해줘.
다른 언어에서는 [C++의 *unordered map*](https://en.cppreference.com/w/cpp/container/unordered_map),
[Python의 *dictionary*](https://docs.python.org/3/tutorial/datastructures.html#dictionaries), 또는 *연관 배열(associative array)*이라고도 불러.

Vec을 다룰 때 이야기했던 또 다른 자료구조(data structure)야.
