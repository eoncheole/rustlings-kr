# 문자열(Strings)

Rust에는 두 가지 문자열 타입이 있어: 문자열 슬라이스(string slice, `&str`)와 소유된 문자열(owned string, `String`)이야.
언제 어떤 걸 써야 하는지 딱 정해주진 않을 거지만, 각각을 구별하고 만들고 사용하는 방법을 보여줄게!
