# 에러 처리(Error Handling)

대부분의 에러는 프로그램을 완전히 멈출 만큼 심각하지 않아.
함수가 실패할 때, 쉽게 해석하고 대응할 수 있는 이유인 경우도 있어.
예를 들어, 파일을 열려고 했는데 파일이 존재하지 않아서 실패했다면, 프로세스를 종료하는 대신 파일을 새로 만들고 싶을 수도 있잖아.
