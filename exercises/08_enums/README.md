# Enums

Rust에서는 가능한 값들을 나열하는 "enum"이라는 타입을 정의할 수 있어.
enum은 많은 언어에 있는 기능이지만, 각 언어마다 그 능력이 달라. Rust의 enum은 F#, OCaml, Haskell 같은 함수형 언어의 대수적 데이터 타입(Algebraic Data Type)과 가장 비슷해.
enum과 함께 유용한 것이 Rust의 "패턴 매칭(Pattern Matching)"이야. 열거형의 각 값에 따라 다른 코드를 쉽게 실행할 수 있게 해줘.
