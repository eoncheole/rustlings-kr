# 매크로(Macros)

Rust의 매크로(Macro) 시스템은 매우 강력하지만, 이해하기가 좀 어려울 수 있어.
여기서는 완전한 매크로를 직접 작성하는 법을 가르쳐주진 않을 거야.
대신, 매크로를 사용하고 만드는 방법을 보여줄게!

매크로 작성에 대해 더 배우고 싶다면,
[macrokata](https://github.com/tfpk/macrokata) 프로젝트를 확인해봐.
Rustlings와 비슷한 스타일의 연습문제인데, 매크로 작성을 배우는 데 특화되어 있어!
