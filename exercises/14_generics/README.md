# 제네릭(Generics)

제네릭(Generic)은 타입과 기능을 더 넓은 범위로 일반화하는 주제야.
코드 중복을 줄이는 데 정말 유용하지만, 문법이 좀 복잡할 수 있어.
제네릭을 사용하려면 제네릭 타입이 실제로 어떤 타입에 대해 유효한지 꼼꼼하게 지정해야 해.
가장 간단하고 흔한 제네릭 사용법은 타입 매개변수(type parameter)야.
