# 스레드(Threads)

대부분의 현재 운영체제에서, 실행된 프로그램의 코드는 프로세스(Process) 안에서 돌아가고, 운영체제는 여러 프로세스를 동시에 관리해.
프로그램 안에서도 독립적으로 동시에 실행되는 부분을 만들 수 있어. 이렇게 독립적인 부분을 실행하는 기능을 스레드(Thread)라고 불러.
